independently report backend model identity; selected settings and launch hashes

## Accounting and decision

All 34 answers across both products passed independent cost-blind grading:
202 applicable dimensions passed, two symmetric initial-change dimensions were
not applicable, and none were partial or failed. All ten planned native sessions
completed with unchanged inputs; there were no native retries or timeouts.
In-session command failures and warnings remain in the recorded usage.

Native `turn.completed.usage` supplies input, cached input and output. Cached input
is a subset of input. **U = input − cached input + output** and **T = input + output**.
The primary alternative workflow allocation is the shared initial plus that arm's
two returns. Equal initial attribution to each alternative is not two executed
initial sessions. Actual study totals count each real session once.

Pair 1 lowers T while pair 2 raises it. The two-return aggregate also misses
the U threshold. Smaller projections do not establish a meaningful token saving.

The actual two-product study used **447,569 U / 1,855,697 T**, counting each
shared initial once and every return once. Seven sessions ran before the config
interruption and three resumed under the reviewed amendment. These actual totals
must not be calculated by adding the alternative workflow allocations.

The predeclared rule requires complete quality/freshness, at least 10% lower
primary U and no higher primary T. Every pair and the return-only aggregate remain
visible; two pairs cannot establish robust, causal or universal savings. Provider
cache and reader strategy vary despite identical local source caches.
