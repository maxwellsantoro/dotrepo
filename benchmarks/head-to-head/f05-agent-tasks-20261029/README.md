# F-05 source enrollment, October 29, 2026

This is a source-only curation packet, not a frozen runnable experiment or a
campaign result. The retained roster enrolls twelve tasks in twelve distinct repositories in
prescribed queue order: three tasks per ecosystem, six repository/six component
tasks and six pre-clone/six local-checkout tasks. No dotrepo index, profile, crawler/importer output or E1 qualification
output was consulted. No upstream code or autonomous agent session was executed.

`tasks.json` owns enrollment; `screening.json` retains exclusions and source
lookup failures. Exact upstream source bytes, metadata, immutable commits, URLs,
line locators and SHA-256 bindings are retained under `sources/` and in
`source-catalog.json`. API metadata is retained as the connector's returned JSON;
repository source files are decoded from GitHub's base64 blob content.

Only `requests/` contains prospective agent task requests. `curator/`, `sources/`,
this packet and sibling experiment materials must be inaccessible to future
agents except ordinary upstream files acquired through their allowed source
channels. Runtime enforcement of that separation is pending. Curator context is
Codex worker `/root/e1_establishment`, which previously authored E1 development
code; source curation began afterward and no extractor changes/tuning are made
from these F-05 sources. Fresh future sessions must not inherit curator history.
This is operator/model curation, not independent participant use or proof of
absence of model pretraining exposure.

Gold distinguishes complete applicable tuples from required abstention and
unresolved evidence. Missing instructions and setup do not remove enrolled tasks.
Draft oracles retain intended scope and execution criteria but need independent
review, executable controls and a pinned environment before launch. Model,
budgets, consumer policy, immutable evaluated snapshot, cost rates, isolation and
72-session assignment remain unset; no source-only artifact authorizes execution.

`SOURCE_FREEZE.json` binds this source roster, screening decisions, all retained
inputs and draft scoring materials. `verify_source_freeze.py` checks the hashes,
upstream Git blob bindings, quotas, queue traversal, historical/E1 separation,
source locators and request/gold path separation. That local verification checks
packet integrity; it cannot establish upstream correctness, runtime isolation,
independent curation or consumer benefit. Frozen rules are copied under `rules/`.

Two provisional source-supported alternatives are retained for independent
review: the Microsoft TypeScript default Go test wrapper and OpenHands' documented
suite-selection mechanism bound to its dedicated CLI launcher suite. Other tasks
retain required-abstention or unresolved complete tuples. This mix was observed
after enrollment; no repository was replaced for incomplete instructions.

Pending launch items are task-specific executable oracle review, exact runtime
and dependency images, symmetric permissions/cache/budgets, model settings, cost
rates, immutable evaluated snapshot and consumer policy, randomized 72-session
assignment, provider usage receipts and enforced access controls. Freeze those
under a separate campaign manifest before execution. Source-level tuple support
does not show that prerequisites are installed or that a command succeeds.
