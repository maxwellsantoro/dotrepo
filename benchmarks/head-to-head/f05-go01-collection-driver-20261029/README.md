`process_io.py` copies the reviewed bounded client transport. The only behavioral
extension catches cancellation as well as ordinary failures, kills the fake/real

is used to establish a listing. Attempt/result/trace records survive preflight and
authorization failures with zero daemon calls. Every attempted create triggers
forced removal, inspect and responsive owned-name absence checks; uncertainty is
incomplete. Work, provisioned bytes and receipt timing are retained; dollar costs
remain null. No byte-to-token accounting is introduced.

Node observer computes the complete path/type/regular-byte tree digest/counts before
and after, matching a Python expectation from validated source archive members and
implicit/explicit directories. Added `go.work.sum`, generated files, deletions,
symlinks/type changes and byte changes fail. All permitted build/tmp outputs are
outside the repository. Rows are sorted by UTF-8 path bytes (Python `encode()` and
Node `Buffer.compare`), serialized as compact JSON arrays with literal Unicode and
one LF per row, then UTF-8 SHA256-hashed. Only digest/counts leave the container.
These are observations at two instants, not a proof of immutability between them.
File modes and arbitrary concurrent hostile filesystem behavior are not proved.
